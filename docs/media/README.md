# README 演示素材

图片与动图均来自项目实际运行的 4K / 60 fps 录制，所用实现版本为 `4379425b558a99261d36c5e512813aa9b510ac2a`，其功能已合入主分支。素材仅用于文档展示，不参与应用运行。

| 文件 | 展示内容 | 交互录制时间 |
| --- | --- | --- |
| `archive.jpg` | 主档案阵列 | 1 秒 |
| `detail.jpg` | 研究记录与收藏 | 43 秒 |
| `search.jpg` | 按编号检索 | 35 秒 |
| `assembly.jpg` | 模型拆解 | 66 秒 |
| `browse.gif` | 循环切列与翻阅 | 3.8–8.3 秒 |
| `assembly-motion.gif` | 拆解、旋转与重组 | 58.8–70 秒 |

截图以 1600 × 900 JPEG 保存。两张 GIF 分别压缩为 640 像素宽 / 8 fps 和 840 像素宽 / 12 fps；它们的帧率与调色板不代表应用的实时渲染质量。
